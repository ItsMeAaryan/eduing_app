Critical Blockers — Must fix before any release

  • ALL providers use hardcoded mock data — zero real Firestore reads in any feature provider
  • GEMINI_API_KEY injected via --dart-define; falls back to string "mock_key" — will silently fail in production builds
  • No auth guard in router — unauthenticated users can reach all routes by navigating directly
  • firebase_options.dart / google-services.json NOT in repo — app cannot build for any real environment
  • No dark mode — lightTheme only, no darkTheme, ThemeMode.system ignored
  • Document upload FAB does nothing (onPressed: () {})
  • Application "Add" button does nothing (onPressed: () {})
  • All search bars are non-functional UI decoration (no TextEditingController, no actual search)
  • BackgroundTaskService registered in notification_provider but never called in main()
  • Only 1 test file, 35 lines, tests only a data model — zero widget tests, zero integration tests
  • No app signing config in android/app/build.gradle — Play Store submission blocked
  • No GoogleService-Info.plist reference in iOS project — App Store submission blocked

UI/UX Review — Screen-by-Screen Issues

Auth Screen

Issue
Password field has no visibility toggle (eye icon). Users cannot see what they typed.
Add obscureText toggle with suffix IconButton.
Issue
Email validation regex is just contains('@') — accepts "a@" as valid email.
Use proper regex or email_validator package.
Issue
Error shown via SnackBar after async. If user rotates phone, context may be invalid. Uses !mounted check but then reads ref after it.
Read error state before async gap, not after.
Issue
No Google / Apple sign-in buttons in UI despite being in feature list. Auth screen looks incomplete.
Issue
No keyboard dismiss on tap outside. Form submits on Enter in email field but not password field.

Universities Screen

Issue
Search bar is fake Container — no user input possible. This is the primary discovery mechanism. Critical miss.
Issue
Filter chips visually update (selectedFilter state) but list doesn't change — misleading UX.
Issue
Hardcoded avatar URL in header (pravatar.cc) — shows random stranger's photo, not logged-in user.
Issue
"Sort by: AI Match" is static Text + Icon — not a real dropdown.
Issue
List has no pull-to-refresh and no infinite scroll. 4 items with no pagination signal.

Documents Screen

Issue
AI Document Health card has shimmer animation on the title Row permanently (onPlay: c.repeat) — distracting and misleading as a "loading" signal.
Issue
Circular indicators show hardcoded 80/92/85% regardless of actual documents.
Issue
Scan icon in header CircleAvatar does nothing.

Mock Interview Screen

Positive
Best-designed screen. Dark video UI, pulsing mic animation, question overlay. High-quality shell.
Issue
Timer is hardcoded "12:45" — doesn't count up or down.
Issue
No actual camera or microphone integration. "Camera Active" text but no camera feed.
Issue
Mic button pulsing animation but no recording state.

AI Copilot Chat

Positive
Streaming chat is actually wired end-to-end. Most complete feature in the app.
Issue
Attach icon does nothing. No file or document context injection into prompt.
Issue
No conversation history persistence. Session resets on screen pop.
Issue
Typing indicator uses three dots that all fade in/out simultaneously (same duration, just delayed) — looks off. Should stagger up-down like iMessage.

Global / Cross-Cutting

Issue
AppColors.withOpacity() deprecated in Flutter 3.3+. Should use .withValues(alpha:) or Color.fromRGBO. Will produce deprecation warnings everywhere.
Issue
No loading state UI for any async operation except auth. If Firestore reads were added, users would see blank screens.
Issue
Navigator.of(context).pop() used alongside GoRouter. Mixing navigation systems will cause issues. Use context.pop() from go_router exclusively.
Issue
No consistent page transition — GoRouter defaults to platform default (slide on iOS, fade on Android). No custom transition defined.
Issue
Scaffold uses bottom: false in SafeArea but main_layout.dart bottom nav may overlap content. Inconsistent handling.
Issue
Two duplicate AI service classes: GeminiService and GeminiAIService — different interfaces, overlapping concerns. gemini_service.dart appears unused by any provider.
